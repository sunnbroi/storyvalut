# 📝 StoryVault

**StoryVault** — это простое, но надёжное веб-приложение на Yii2, в котором любой пользователь может оставить сообщение, а другие — его прочитать. Проект построен с учётом безопасности, расширяемости и современного пользовательского интерфейса.

---

## 🚀 Быстрый старт

### 1. Клонируй репозиторий:

```bash
git clone https://github.com/твой-пользователь/storyvault.git
cd storyvault
```

### 2. Установи зависимости:

```bash
composer install
```

### 3. Настрой подключение к базе данных:

Создай файл `config/db-local.php` и укажи в нём параметры доступа:

```php
<?php
return [
    'class' => 'yii\db\Connection',
    'dsn' => 'mysql:host=localhost;dbname=storyvault',
    'username' => 'root',
    'password' => '',
    'charset' => 'utf8',
];
```

> ⚠️ Файл `db-local.php` не должен попадать в git (добавлен в `.gitignore`).

> Если ты используешь SQLite:

```php
'dsn' => 'sqlite:@app/data/storyvault.sqlite',
```

### 4. Запусти миграции:

```bash
php yii migrate
```

### 5. Запусти локальный сервер:

```bash
php yii serve
```

Открой в браузере: [http://localhost:8080](http://localhost:8080)

## ⚙️ Возможности

- Гостевые сообщения без регистрации
- Возможность редактировать и удалять сообщение по приватной ссылке
- Встроенная капча и защита от спама
- Безопасная обработка HTML
- Сессионные токены и IP-анализ
- Чистая архитектура и расширяемая структура

## 🛡 Безопасность

- CSRF-защита включена
- Антиспам: ограничение 1 сообщение с IP каждые 3 минуты
- Валидация и очистка пользовательского ввода
- Генерация приватных ссылок с уникальными токенами
